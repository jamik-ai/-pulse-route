Архитектура
===========

Три логических компонента работают в двух Docker-сервисах: **ML-сервис** (инференс и обучение), **backend** (приём
потока, оркестрация, API) и **BI-дашборд** (статическая страница, отдаётся backend'ом). Backend обращается к
ML-сервису по HTTP; ML-сервис без состояния и масштабируется копиями.

.. code-block:: text

    эмулятор NDTP / терминалы ──TCP :9201──▶ ┌──────────────── backend (FastAPI) ────────────────┐
    архив validate (replay)  ──────────────▶ │ NDTP-кодек → OnlineEngine: буфер ТС, признаки ≤ T  │
                                             │ прогноз каждые 5 мин · REST API · дашборд · отчёт  │
                                             └───────────────┬───────────────────────────────────┘
                                                             │ POST /v1/predict (батч всех ТС)
                                             ┌───────────────▼─────────────────┐
                                             │ ML-сервис (FastAPI + CatBoost)   │
                                             │ задержка · P(late) · интервал ·  │
                                             │ причины (SHAP) · /v1/model/reload│
                                             └──────────────────────────────────┘

Контейнеры
----------

.. list-table::
   :header-rows: 1

   * - Сервис
     - Порт
     - Назначение
   * - ``ml`` (``delay-ml``)
     - 8001
     - Инференс ансамбля, причины, перезагрузка модели без простоя
   * - ``backend`` (``ndtp-server``)
     - 8080, NDTP 9201
     - Приём NDTP, онлайн-движок, API, дашборд, маршруты, аналитика и отчёт
   * - ``backend-synth`` (профиль ``synth``)
     - 8082
     - Второй стенд на синтетике «3 автобуса на маршруте»
   * - ``router`` (профиль ``router``)
     - 5000
     - Свой OSRM на выгрузке OSM Москвы — пути рейсов по дорогам
   * - ``emulator`` (профиль ``emulator``)
     - 18080
     - Эмулятор NDTP организаторов

Запуск
------

.. code-block:: bash

    git clone https://github.com/jamik-ai/-pulse-route.git pulse-route && cd pulse-route
    unzip /путь/к/dataset.zip -d data          # или DATASET_DIR в .env
    cp .env.example .env                       # логин/пароль дашборда
    docker compose up -d --build               # ml + backend; архив сразу проигрывается как поток NDTP

Структура кода
--------------

.. list-table::
   :header-rows: 1

   * - Путь
     - Содержимое
   * - ``src/dataio.py``, ``src/augment.py``, ``src/synth.py``
     - Загрузка датасета, аугментация обучающей выборки, синтетика
   * - ``src/features.py``, ``src/passes.py``
     - Признаки на момент T, детекция проездов остановок
   * - ``src/train.py``, ``src/train_aux.py``, ``src/predict.py``, ``src/explain.py``
     - Обучение ансамбля и вспомогательных моделей, инференс, причины
   * - ``src/realtime/``
     - NDTP-кодек, онлайн-движок, сервер, replay, сабмит и проверки на потоке
   * - ``src/ml_service/``, ``src/backend/``
     - ML-сервис; backend, клиент ML, маршруты по дорогам, дашборд (``static/``)
