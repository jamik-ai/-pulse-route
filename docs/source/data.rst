Данные
======

Датасет хакатона: телеметрия ``traffic.csv``, плановое расписание (в train/test — с фактом прибытия), прогнозные
точки с разметкой ``labels/`` (train/test) и ``validate/points.csv``. Разметка на train/test, скрытый эталон —
по validate.

.. important::

   ``validate/traffic.csv`` совпадает с ``test/traffic.csv``, а факты целевых остановок validate лежат в
   ``train/test/schedule.csv``; синтетические ТС ``9000xxx`` в train — копии ТС test/validate. Эти утечки в
   модели **не используются** (подробно — ``docs/DETAILS.md``).

Синтетика «3 автобуса на маршруте»
----------------------------------

Реальный датасет даёт по одной машине на маршрут. Для демонстрации лент и сбивания в пары генерируется
39 ТС на 13 реальных маршрутах: движение по дорогам, стоянки, отстой на конечных, шум GPS, пропадания связи.
Распределение отклонений подогнано под реальное (90-й перцентиль ≈ 260 с против 278 с, опоздания > 2 мин — 26 %).

.. code-block:: bash

    ./run.sh python -m src.synth        # → output/synthetic/{schedule.csv, traffic.csv, meta.json}
