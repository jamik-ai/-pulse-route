Опоздания > 2 мин на потоке: предупреждение выдано по 70 из 86 (81 %), ложных — 20 из 90. Ранние прибытия
< −1 мин помечены в 36 из 49 случаев.

Калибровка
----------

На кросс-валидации (1 494 точки, не участвовали в обучении): P(опоздание) — AUC 0,86, Brier 0,114; интервал ~80 %
с конформной поправкой накрывает факт в 80 % случаев. Оценка на одном дне потока оптимистична — эти точки были в
обучении (подробно — ``docs/RELIABILITY.md``).

Производительность
------------------

* ML на батч всех ТС: p50 ≈ 100 мс, p95 ≈ 300 мс; пересчёт такта (признаки + ML) 0,3–0,4 с.
* Поток NDTP обрабатывается без очередей, 0 ошибок CRC.
* Холодный старт: ML ~11 с, backend ~14 с.

Деградация
----------

* ML-сервис недоступен → прогноз по правилу, баннер, автоматический возврат к модели.
* Обрыв потока NDTP → «нет связи», последнее известное состояние, переподключение.
* GPS-выбросы фильтруются для отображения; ТС без свежих данных показываются серым, а не «по графику».
